# 📰 AI News Research Tool

An AI-powered news summarization app built using Streamlit, Groq LLM, and NewsAPI.

## 🚀 Live App
https://ai-news-research-tool-ksul8un8d5gafablhu6fmy.streamlit.app/

---

## 📌 Features

- AI-generated news summaries
- Sentiment Analysis
- Latest News Fetching
- Interactive UI using Streamlit
- Category-based news filtering
- Charts and analytics

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Groq API
- NewsAPI
- Pandas
- Plotly
